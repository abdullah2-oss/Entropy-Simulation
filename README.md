# Entropy Simulation

## Project Overview
This project simulates how entropy and heat transfer change as the temperature of a material increases.

## Project Objectives
- Calculate entropy change at different temperatures.
- Calculate the heat transferred to the material.
- Visualize the relationship between temperature, entropy, and heat transfer.

## Equations Used

**Entropy Change:**

ΔS = mc ln(Tf / Ti)

**Heat Transfer:**

Q = mc(Tf - Ti)

## Libraries Used
- **NumPy:** Used for numerical calculations and generating temperature values.
- **Matplotlib:** Used to create graphs and visualize the results.

## Project Parameters
- Mass: 2.0 kg
- Specific Heat Capacity: 900 J/(kg·K)
- Initial Temperature: 300 K
- Final Temperature Range: 300–1000 K
- Number of Temperature Values: 100

## Project Files
- `entropy_simulation.py` – Python source code.
- `Entropy_Project.pdf` – Project report in PDF format.

## Results
The simulation shows that:
- Entropy change increases as temperature increases.
- Heat transferred increases linearly with temperature.
